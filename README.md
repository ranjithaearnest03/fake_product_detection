# Smart Fake Product Detection System

A Python desktop application that detects counterfeit products by scanning barcodes and matching them against a local database of verified products.

## Features
- **Admin Login**: Add new products by scanning barcodes or typing them manually.
- **User Verification**: Scan a barcode to instantly check if a product is genuine or fake.
- **Local Database**: Uses SQLite to store product information securely.
- **Barcode Scanning**: Uses OpenCV and Pyzbar for real-time camera-based scanning.

## Tech Stack
- **Language**: Python 3
- **GUI**: Tkinter
- **Database**: SQLite3
- **Scanning**: OpenCV, Pyzbar
